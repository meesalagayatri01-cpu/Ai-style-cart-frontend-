# AI Style Cart — Frontend

A responsive React + Vite fashion storefront demo.

## Run on your computer
1. Install Node.js (LTS) from https://nodejs.org/
2. Extract this ZIP.
3. Open the extracted `ai-style-cart-frontend` folder in VS Code.
4. Open Terminal → New Terminal.
5. Run:

   npm install
   npm run dev

6. Open the local URL Vite prints (usually http://localhost:5173).

## Included
- Responsive fashion storefront
- Product cards and category filters
- Search, favourites, demo cart counter
- Style Studio mood selector
- Demo product photos from Unsplash

## Important
This is the frontend only. Cart, favourites and style selection are browser-demo interactions; they are not connected to a backend, login, database, payments, or AI service yet. Product photos and Google Fonts need internet access.
